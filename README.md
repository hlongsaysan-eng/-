# ระบบใบเสนอราคา

ระบบออกใบเสนอราคาสำหรับใช้งานบนคอมพิวเตอร์เครื่องเดียว ใช้ Node.js ที่ติดตั้งอยู่แล้ว ไม่ต้องติดตั้งแพ็กเกจเพิ่มและไม่ต้องต่ออินเทอร์เน็ต

## วิธีเปิดใช้งาน

1. ดับเบิลคลิก `เปิดระบบ.bat` — เบราว์เซอร์จะเปิดหน้า http://localhost:3900 ให้เอง
2. ครั้งแรกระบบจะให้สร้างบัญชีผู้ดูแลระบบ จากนั้นกรอกข้อมูลบริษัทที่หน้า **ตั้งค่า**
3. ปิดหน้าต่างสีดำเมื่อต้องการหยุดระบบ

## ขั้นตอนการทำงาน

ร่าง → ส่งขออนุมัติ → อนุมัติ / ส่งกลับแก้ไข → ส่งลูกค้า (พิมพ์, PDF, LINE) → ลูกค้าตอบรับ / ปฏิเสธ → สร้างใบสั่งขาย / ใบแจ้งหนี้

| บทบาท | สิทธิ์ |
| --- | --- |
| พนักงานขาย | สร้างและแก้ไขเอกสารของตนเอง ดูเอกสารทุกใบ |
| ผู้อนุมัติ | อนุมัติ / ส่งกลับ และจัดการเอกสารทุกใบ |
| ผู้ดูแลระบบ | ทุกอย่าง รวมถึงตั้งค่า จัดการผู้ใช้ และสำรองข้อมูล |

ที่หน้าตั้งค่ากำหนดได้ว่าใบเสนอราคายอดต่ำกว่ากี่บาทให้อนุมัติอัตโนมัติ (0 = ต้องอนุมัติทุกใบ)

## ข้อมูลและการสำรอง

- ข้อมูลทั้งหมดอยู่ในโฟลเดอร์ `data` (ฐานข้อมูล `quotation.db` และไฟล์ PDF ใน `data/pdf`)
- สำรองข้อมูลได้ที่ **ตั้งค่า → ดาวน์โหลดไฟล์สำรอง** หรือคัดลอกโฟลเดอร์ `data` ทั้งโฟลเดอร์ขณะปิดระบบ
- กู้คืน: ปิดระบบ แล้วนำไฟล์สำรองมาวางแทน `data/quotation.db` (ลบไฟล์ `quotation.db-wal` และ `quotation.db-shm` ถ้ามี)

## โครงสร้างไฟล์

- `server.js` — เซิร์ฟเวอร์ ฐานข้อมูล สิทธิ์ และขั้นตอนเอกสาร
- `lib/calc.js` — สูตรคำนวณยอดเงิน ภาษี และตัวอักษรจำนวนเงิน (ใช้ร่วมกันทั้งเซิร์ฟเวอร์และหน้าเว็บ)
- `lib/print.js` — แบบฟอร์มเอกสาร A4
- `public/` — หน้าเว็บ
